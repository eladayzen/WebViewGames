# Archived: second background music pass (slower/relaxed take)

The track that was live in `src/assets/audio/music_bed.mp3` from
2026-07-26 until 2026-08-19. It superseded the original "Midnight Rooftop
Dash" (see `art/archive/music-bed-v1-fast-funk/`) as a deliberately
slower, less busy take -- direction at the time was that the original was
too punchy/cluttered to hold up over long listening.

Superseded again (2026-08-19): direct feedback that this one was *still*
annoying, despite already being the "calmer" revision. Numeric analysis
(tempo/spectral-centroid comparison against HalfShellHustle's music_theme.mp3,
which the same feedback called out as a positive reference) found this
track reads as notably muddier/darker than HalfShellHustle's (spectral
centroid ~990-1157 Hz here vs. ~2554 Hz there) -- suggesting the actual
problem was never really tempo, it was brightness/clarity. The replacement
was generated aiming for that brighter, more clearly-produced character
instead of simply going slower again.

Music was also OFF by default the whole time this track was live (per a
2026-07-30 request) -- it's back on by default as of the 2026-08-19 swap.
